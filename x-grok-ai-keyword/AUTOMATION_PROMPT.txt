【核心 KPI】
不要把“发现 AI 新闻数量”当成功指标。真正目标是尽可能早发现“过去几乎不存在、现在开始形成真实搜索需求”的新 Root / 新组合词 / 新工作流 / 新站点机会。

重点发现：
1. 新 AI 产品、模型、品牌
2. 新模型 + 已有产品/平台形成的新组合词
3. 新功能、新玩法、新工作流
4. 新职业 AI 工作流
5. 突然被多人讨论的新 AI 概念
6. 过去 30–90 天几乎不存在、最近 24–72h 开始出现的新词
7. 可以做 Tool / Generator / Checker / Calculator / Directory / Database / Tutorial / Comparison / Template / API / pSEO 的词
8. 新站点反向暴露出来的新 Root

【时间】
优先过去 24h，同时回看 72h、7d、30d，必要时 90d，判断是否真正从 0 开始起量。

【信息源】
优先 X/Twitter：
@_akhaliq、Hugging Face、OpenAI、Google/DeepMind、Anthropic、Meta AI、xAI、DeepSeek、Qwen/Alibaba、Microsoft AI、NVIDIA AI、Stability AI、Black Forest Labs、Runway、Midjourney、ElevenLabs、Replicate、fal.ai、Cursor、Ollama、LM Studio、ComfyUI 等。

不要只盯大厂。个人开发者、小团队和刚上线的小站优先。

【状态】

IDEA = 无真实需求证据

【执行纪律】
每轮顺序：
